# blue-white-ppt 1.1.0-rc.3

Complete skill package with native editable blue-and-white PowerPoint authoring, 39 component codes, 244 variants and the approved 53-page visual reference.

## Included updates

- Compact references: trapezoid 13 pages / 32 compositions; Morph 14 pages / ten effect families; content and playback six pages.
- All 33 pages retain the original fixed summary bar, native double chevron, complete gray-blue content frames, and separate logical chapters and physical page numbers.
- Portable standalone sources for trapezoid and Morph examples, bundled fonts and examples, capability records and regression tests.
- Native API, grouping, layering, XML, bounds, distribution and C19 parameter fixes accumulated since 1.0.0.

## Download and install

Download `blue-white-ppt-skill-v1.1.0-rc.3.zip` from this repository. Extract the complete `blue-white-ppt/` folder and read its `SKILL.md` and `README.md`. The ZIP contains the complete matching source for this candidate.

Generation uses Node.js 20+ and built-in modules. No npm dependencies, Python, Codex API or network access are needed for generation. Font files are included under their OFL license and should be installed on the viewing machine.

## Validation and scope

The source checkout and a clean extraction each passed 32 tests. All 33 reference pages were rendered and reviewed in Microsoft PowerPoint. Six Morph transitions and the trapezoid transition were sampled in native video exports. The approved reference, previews, fonts and core script bytes match the preceding candidate.

This is a release candidate. General equation, chart-data, click-step and Morph-recipe compilers remain experimental. Full interactive formula/chart editing and live-click acceptance, and remote cross-platform CI, are separate checks. The supplied PPTX files retain native editable objects.
